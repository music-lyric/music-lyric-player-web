# music-lyric-player

> An animation-rich, highly customizable web lyric player.

Full documentation, examples, and API: **[music-lyric/music-lyric-player-web on GitHub](https://github.com/music-lyric/music-lyric-player-web)**

## Install

Lyric data is parsed by [`music-lyric-kit`](https://github.com/music-lyric/music-lyric-kit-node), which must be installed alongside the player.

```js
import { BaseLyricPlayer, DomLyricPlayer } from 'music-lyric-player'
```
